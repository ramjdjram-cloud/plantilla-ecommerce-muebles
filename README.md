# Tienda de Muebles

Plantilla web estática de una tienda de muebles, construida únicamente con **HTML** y **CSS** (sin frameworks ni JavaScript).

## 🖥️ Vista general

Sitio sencillo y responsive con portada, catálogo, blog, galería y página de contacto. Pensado como punto de partida para practicar maquetación o como base para un proyecto más grande.

## 📄 Páginas

| Archivo | Descripción |
| --- | --- |
| `index.html` | Inicio: hero, categorías y productos destacados |
| `nosotros.html` | Información sobre la empresa |
| `tienda.html` | Catálogo de productos |
| `blog.html` | Listado de entradas del blog |
| `entrada.html` | Detalle de una entrada del blog |
| `galeria.html` | Galería de imágenes |
| `contacto.html` | Formulario de contacto |

## 🚀 Cómo usarlo

1. Clona el repositorio:

   ```bash
   git clone https://github.com/ramjdjram-cloud/plantilla-ecommerce-muebles.git
   ```

2. Abre `index.html` en tu navegador.

   > También puedes levantar un servidor local, por ejemplo:
   > ```bash
   > python3 -m http.server
   > ```
   > y visitar `http://localhost:8000`.
